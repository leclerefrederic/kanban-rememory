# Kanban Rememory: standalone work

This skill only routes you to the kit's instructions. It restates no rule: the documents named here are the single source.

## Read first

- `AGENTS.md`
- `agents/work-in-a-project.md`
- `agents/lean-specifications.md`
- `documentation/lean-specifications.md`

## Read when needed

| Situation | Read |
| --- | --- |
| Create, move or close a card, or review the board | `agents/kanban/board-guide.md` |
| Write the outcome and criteria of a card | `agents/kanban/write-task-cards.md` |
| Record a milestone or hand work over | `agents/maintain-rememory.md` |
| `project/kanban/workflow.json` is missing | `agents/configure-a-project.md` |
| The project uses the software workflow profile | `agents/kanban/software-development-workflow.md` |
| The request involves a Specification or Batch | the Specification Agent or Development Agent skill |

## Before acting

State your role, the active card, and the next authorized action. If the card, the journal and the Git state disagree, report it and stop.
