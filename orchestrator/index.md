# Agent instruction router

Internal execution instructions; human guides live in `documentation/`. Start from `AGENTS.md` and [Card delivery](actions/deliver-card.md), then load only what the next step needs.

| Task | Load |
| --- | --- |
| Create, move or inspect Cards | [Kanban rules](guidelines/kanban.md), [Card content](actions/write-card.md), [board commands](actions/manage-board.md) |
| Locks, checks or recovery | [Module coordination](actions/coordinate-modules.md) |
| Journal entry | [Rememory](actions/maintain-rememory.md) |
| Telegram alerts | [Notify](actions/notify-user.md) |
| Adopt or upgrade | [Install](setup/install.md) |
