# Maintain Rememory

Keep one project journal in `project/rememory/`. Create one `YYYY-MM-DD.md` file on each date with an entry, using the [daily template](../templates/rememory-day.md). Insert each new milestone below the date heading. Use the configured project timezone.

Record project decisions, changes in priority, useful resumption notes and one concise milestone per verified publication. Include the result, the relevant Card link and the published revision when applicable. Name affected modules when that helps find the entry. A cross-module delivery has one milestone. Keep secrets and personal data out of the journal.

Use [delivery coordination](coordinate-modules.md) to serialize writes and avoid duplicate publication entries. Search by stable Card ID when resuming. Each module Kanban is the source of truth for its Cards' stages.

Legacy projects use their configured journal paths.
