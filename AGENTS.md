# Working instructions

Read the [shared working instructions](docs/agents/work-in-a-project.md) before adopting the kit or working on cards.

## Rules for the Kanban Rememory repository

This repository uses its own cards and journal to track changes to the kit. The journal uses Europe/Paris time, and work in progress is limited to one card across Development and Code Review. Select the oldest eligible backlog card by ID unless an agreed priority is documented on the card. Review blockers and flow at closure or before resuming interrupted work. Adapt this section for the target repository.

Publish each verified change to `origin/main` after closing its card. The repository owner has granted standing authorization for these pushes.
