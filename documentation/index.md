# User guides

These guides explain how Kanban Rememory supports your project, what the records mean and which decisions belong to you. The agent writes and maintains the records; you can read them without learning the commands or formats.

Start with [Understand the framework](understand-the-framework.md) and the shared principles in [Lean specifications](lean-specifications.md).

| You want to… | Guide |
| --- | --- |
| Set up Kanban Rememory in a repository | [Start a project](start-a-project.md) |
| Give the agent work and agree on its priority | [Assign a task](assign-a-task.md) |
| Recover an interrupted session | [Resume work](resume-work.md) |
| Describe a problem and track its resolution | [Report a defect](report-a-defect.md) |
| Use ChatGPT, Claude or both on one project | [Use with ChatGPT and Claude](use-with-chatgpt-and-claude.md) |
| Understand which decisions remain yours | [Your responsibilities](user-responsibilities.md) |
| Set up optional private Telegram alerts | [Telegram setup](telegram-setup.md) |

A guide does not grant the agent permission to change scope, accept a delivery or publish code. The separate [agent instructions](../orchestrator/index.md) define how the agent executes the work.
