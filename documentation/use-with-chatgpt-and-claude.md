# Use Kanban Rememory with ChatGPT and Claude

Kanban Rememory uses the same records and working method with Codex and Claude Code.

## Coordinate from one chat

Open a normal session in the project. Codex reads `AGENTS.md`; Claude Code reads it through `@AGENTS.md` in `CLAUDE.md`. The Orchestrator frames the Card, implements it, verifies the result and carries it through authorized publication in that chat. You decide scope and acceptance; publication follows the project's permissions.

Instructions apply in every host, but no host enforces them: they rely on the agent and on each product's own sandbox and approval controls.

## Change assistants or resume later

Project interfaces and conversation histories differ between products; a chat in one application does not carry into another. Identify the repository and, if known, the Card. Ask the new session to recover the state from the Card and the project journal and continue the next authorized action. [Resume work](resume-work.md) explains what to expect.
